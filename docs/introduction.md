# Introduction

**TrueDotBin.CosmosUtils** is a utility package containing QoL features for Cosmos kernels.

## Features

This utility package includes utility methods for **logging**, **graphics**, **loading embedded resources**, and **the file system**.

For more information, read [the repository's README][repo-readme]
